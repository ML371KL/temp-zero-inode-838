# Walk-forward бэктест «Сейсмостанции 21M»

> **Замороженный исследовательский архив.** С 2026-07-19 live-логика зафиксирована как
> `btc-allocation-policy-v1`. Повторный запуск файлов этой директории не меняет live-пороги и не
> является перекалибровкой. Исполняемый контракт и правила выпуска следующей политики описаны в
> [`../POLICY.md`](../POLICY.md).

Инструментарий, на котором проверялась экономическая калибровка панели (аудит 2026-07-14,
переход v2.7.3 → v2.8.0). Реконструирует семейные баллы, блоки, взвешенные шкалы и дерево
гейтов вердикта на каждый день 2018–2026, используя на дату t только данные ≤ t.

## Файлы

| Файл | Назначение |
|---|---|
| `download.mjs` | скачивает полные истории из тех же бесплатных источников, что и панель (FRED CSV, Coinbase-свечи с 2015, Coin Metrics community, The Block ETF, DefiLlama, Blockchain.com, CFTC, Deribit DVOL) в `data/` |
| `engine.mjs` | walk-forward реконструкция всех семейных баллов и режимов → `out/timeline.json` |
| `eval.mjs` | форвардные доходности по режимам, IC семей/блоков, корреляции семей, симуляции стратегий, whipsaw, чувствительность полос/MVRV → `out/report.json` |
| `eval2.mjs` | варианты улучшений: карты позиций, override детекторов, dwell-фильтры, распределение балла, матрица переходов → `out/report2.json` |
| `eval3.mjs` | финальное сравнение v2.7.3 против v2.8.0 на одних данных → `out/final-comparison.json` + `out/chart-data.json` |

## Запуск

```
node backtest/download.mjs   # ~2-3 минуты, сохраняет data/*.json + _manifest.json
node backtest/engine.mjs
node backtest/eval.mjs
node backtest/eval2.mjs
node backtest/eval3.mjs
```

`data/` и `out/` закоммичены по состоянию на 2026-07-14, чтобы результаты аудита были
воспроизводимы без сети; свежий прогон просто перезапишет их.

## Ограничения (важно при чтении цифр)

- Не реконструируемы (нет бесплатной истории): премия США, funding/OI/basis, спред площадок,
  пеги, skew. Эти семьи отсутствуют в бэктесте так же, как отсутствуют в живой панели при
  геоблокировке — покрытие обрабатывается теми же правилами.
- HY OAS (FRED, лицензия ICE) доступен только за ~3 последних года — до 2023-07 семья
  стресса считается из 2 компонентов.
- Форвардные окна перекрываются: «n дней» ≫ эффективного числа независимых наблюдений;
  hit-rate крайних режимов — это единицы эпизодов, а не сотни.
- v2.8.0 калибровалась на той же истории, на которой оценивалась: цифры «после» означают
  «согласуется с данными», а не «гарантировано вне выборки».

## Дополнение аудита 2026-10-10: `eval6.mjs`

Аудит нашёл в `eval.mjs` … `eval5.mjs` несогласованность: капитал считается с задержкой исполнения в
один день (решение по закрытию `i−1` начинает зарабатывать с дня `i+1`), а ряд для волатильности и
Sharpe строится уже с новой позицией, то есть без задержки. Доходность с просадкой и Sharpe в их
отчётах поэтому описывают две разные стратегии, а сам Sharpe считается не сверх кэша. Архив заморожен:
эти пять файлов и их вывод оставлены как были, а согласованный расчёт вынесен в `eval6.mjs`
(→ `out/audit-2026-10-10.json`). В нём один ряд доходности и для капитала, и для Sharpe; Sharpe — сверх кэша.

Что меняется в числах для лестницы v1 (0/5/20/45/95/100, оверлеи 80/40/60), исполнение на следующий день:

| Окно | Доходность годовых | Sharpe методом архива | Sharpe согласованный | Макс. просадка |
|---|---|---|---|---|
| 2013-01 … 2026-07 | 43,0 % | 1,63 | 1,39 | −40,8 % |
| 2018-06 … 2026-07 | 33,7 % | 1,44 | 1,15 | −40,8 % |

Для сравнения с 06.2018: купить и держать — 30,1 % / 0,70 / −76,7 %; постоянные 35 % — 16,7 % / 0,70 / −36,0 %.
Порядок стратегий не меняется, уровень Sharpe — ниже примерно на четверть.

Ещё `eval6.mjs` считает: чувствительность к задержке исполнения (сделка по тому же закрытию даёт 42,6 %
годовых против 33,7 % на следующий день; на десяти днях преимущество исчезает); частоты режимов и
длительность их жизни; эпизоды recovery-пола и чем они заканчивались; политику без одной семьи; варианты
теневого кандидата v3 (числа его `decision_record` в `docs/policy-v3-candidate.mjs` — отсюда); базу
детекторов; информативность блоков по эпохам. Всё это — та же история, на которой политика
калибровалась: числа описывают, а не доказывают.

## Дополнение 13.10.2026: `eval7.mjs` — правила на часах кандидата

`eval6.mjs` считает на дневной сетке по соглашению архива: наблюдение известно в день, которым датировано,
решение по закрытию дня исполняется на следующем закрытии. Теневой кандидат v3 живёт иначе — фиксирует
решение раз в сутки в заданный час UTC, и к этому часу входы разного возраста:

- ончейн-данные, потоки ETF и закрытая дневная свеча за вчера на месте к 06:00 UTC;
- VIX за рабочий день выходит в FRED на следующий рабочий день в 14-м часу UTC, кредитные спреды — в
  14–16-м, ставки H.15 — в 21-м (зимой на час позже); в воскресенье и понедельник фикс читает четверг;
- баланс ФРС за среду выходит в четверг вечером;
- индекс доллара `DTWEXBGS` публикуется раз в неделю, по понедельникам: на фиксе он старше закрытого дня
  на 3–10 суток;
- отчёт CFTC (срез вторника) выходит в пятницу вечером; архив датирует его днём среза.

`eval7.mjs` берёт те же правила (`build` из `eval6.mjs`), пересчитывает три макросемьи из сырых рядов
архива формулами `engine.mjs` так, что наблюдение становится доступным в момент публикации, сдвигает отчёт
CFTC на первый фикс после публикации и меняет позицию в час фикса по часовым ценам (Bitstamp BTC/USD,
`data/price_bitstamp_hourly.json`) → `out/audit-2026-10-13-fix-hour.json`. Самопроверки встроены: без
задержки публикации пересчёт макросемей совпадает с реконструкцией во все 2 966 суток с 06.2018; час 24
без задержки воспроизводит дневную сетку `eval6.mjs`.

Годовая доходность / Sharpe сверх кэша / макс. просадка, фикс в 06:00 UTC:

| Правила | С 06.2018 | Эра ETF (03.2024+) |
|---|---|---|
| правила v1 на суточном фиксе | 42,3 % / 1,37 / −33,7 % | 21,4 % / 0,91 / −15,8 % |
| сеть по 30-дневным средним | 42,8 % / 1,38 / −33,5 % | 20,5 % / 0,87 / −15,9 % |
| биржи по остатку | 42,5 % / 1,38 / −33,7 % | 22,2 % / 0,94 / −15,8 % |
| оценка: согласие двух окон | 39,8 % / 1,33 / −28,5 % | 21,4 % / 0,91 / −15,8 % |
| пол 40/60/80 по фиксам | 41,4 % / 1,36 / −33,7 % | 21,0 % / 0,90 / −14,7 % |
| **кандидат v3 целиком** | **40,3 % / 1,34 / −28,1 %** | **20,9 % / 0,90 / −14,8 %** |
| без голоса CFTC (линия `v1_no_cftc`) | 44,3 % / 1,45 / −37,7 % | 20,2 % / 0,83 / −17,1 % |

На одних и тех же часах кандидат отдаёт правилам v1 около 2 п.п. годовых с 06.2018 и берёт просадку мельче
на 5,6 п.п.; в эру ETF разница — полпункта. Политика v1 калибровалась на этой истории, кандидат на ней не
подбирался. Большую часть разрыва между строками v1 дневной сетки и суточного фикса (33,7 % → 42,3 %) даёт
время исполнения, которое фикс даёт любому набору правил. Сравнить суточный такт с 15-минутным тактом
живой v1 на истории нельзя — внутридневной истории входов нет; это меряет только форвард (`v1_daily_close`).

**Час фикса.** Кандидат с 06.2018: 06:00 — 40,3 % / 1,34 / −28,1 %; 12:00 — 39,3 % / 1,32 / −28,4 %;
18:00 — 34,4 % / 1,18 / −36,9 %; 23:00 — 35,9 % / 1,23 / −34,3 %; 24:00 — 35,1 % / 1,21 / −36,6 %. Ранний
фикс со старым макро лучше позднего со свежим. Возраст макро при этом не бесплатен: будь макровходы
известны в день, которым датированы, фикс в 06:00 дал бы 41,2 % / 1,37 / −30,7 %, а в эру ETF — 24,6 %
против 20,9 %; большую часть разницы даёт недельная публикация индекса доллара (с долларом как дневным
рядом — 41,1 % и 23,4 %).

**Голос семьи CFTC история не различает.** На дневной сетке архива политика без семьи лучше во всех окнах
(40,9 % / 1,37 против 33,7 % / 1,15 с 06.2018), но архив знает отчёт на три дня раньше публикации. На
часах кандидата с отчётом после публикации разница — +2,0 п.п. годовых с 06.2018 при просадке глубже на
4 п.п. и −1,2 п.п. в эру ETF. Сдвиг отчёта на 0–14 суток от дня среза двигает результат правил v1 от
41,0 % до 47,3 % годовых с 06.2018 и от 16,7 % до 23,6 % в эру ETF — сильнее, чем само наличие голоса.
Поэтому в кандидате семья голосует как в v1, а гипотеза живёт отдельной линией.

Первая версия `eval7.mjs` задавала возраст макро сдвигом на одну строку реконструкции; фикс получал
недельный индекс доллара и пятничные ряды раньше публикации, и кандидат выходил на 45,5 % / 1,51 вместо
42,8 % / 1,43 в том же составе. Числа этой версии нигде не используются.
